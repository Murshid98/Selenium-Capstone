Capabilities

Key Framework Features

🪟
Headed & Headless Mode
Toggle via config.properties — headed for debugging, headless for CI/CD pipelines (2× faster)
📸
Auto Screenshots on Failure
Every failed test captures a screenshot saved to test-results/screenshots/ for instant debugging
⏱
Smart Explicit Waits
WaitUtility class wraps WebDriverWait — no arbitrary Thread.sleep() calls anywhere in the framework
⚙️
Config-Driven Design
Browser, URLs, credentials, timeouts — everything in config.properties, zero hard-coded values in tests
📊
Extent HTML Reports
Timestamped HTML reports after every run — pass/fail details, screenshots, step logs
🚗
Zero Driver Setup
WebDriverManager auto-downloads the correct ChromeDriver — works on any machine without manual setup
Security & Stability

Chrome Guest Mode

Problem Solved
No More Password Manager Popups
Chrome's "Change your password" popup was appearing unpredictably during test runs — sometimes after 2s, sometimes after 5s — making tests flaky and unreliable. The fix uses Chrome's native Guest Mode.
options.addArguments("--guest");
Zero stored credentials No password history Clean isolated session Native Chrome feature No workarounds needed
