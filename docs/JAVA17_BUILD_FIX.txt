ERROR YOU GOT:
  [ERROR] java.lang.IllegalAccessError: class lombok.javac.apt.LombokProcessor
  [ERROR] cannot access class com.sun.tools.javac.processing.JavacProcessingEnvironment
  [ERROR] because module jdk.compiler does not export

ROOT CAUSE:
  Java 17 has a strict module system that blocks access to internal compiler APIs
  Lombok (and other annotation processors) need access to these internal modules

WHAT I FIXED:
  ✅ Updated pom.xml Maven Compiler Plugin with 4 compiler arguments:
     - --add-opens=jdk.compiler/com.sun.tools.javac.processing=ALL-UNNAMED
     - --add-opens=jdk.compiler/com.sun.tools.javac.util=ALL-UNNAMED
     - --add-opens=jdk.compiler/com.sun.tools.javac.code=ALL-UNNAMED
     - --add-opens=jdk.compiler/com.sun.tools.javac.tree=ALL-UNNAMED

  ✅ These arguments allow Lombok and other annotation processors to work
  ✅ No code changes needed - just Maven configuration

================================================================================
                       WHY THIS FIX WORKS
================================================================================

1. Java 17 introduced strict module system (Project Jigsaw)
2. Internal compiler packages are NOT exported by default
3. Lombok needs to access: com.sun.tools.javac.processing
4. Result: IllegalAccessError without proper configuration
5. Solution: Use --add-opens to explicitly grant module access
6. This is the STANDARD approach for Java 17+ with annotation processors
